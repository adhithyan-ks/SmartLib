# COURSE PROJECT REPORT GUIDELINES

**PBCST304 – Object Oriented Programming**

## Report Preparation

The project report must be prepared using LaTeX. Students may use Overleaf or a local LaTeX editor to prepare and compile the report. The final report must be submitted as a PDF.

## Report Sections

1. Title Page

2. Abstract

3. Table of Contents

4. List of Figures

5. List of Tables

6. Introduction

7. Problem Statement and Objectives

8. Requirements Specification

9. System Design

   System Design should include:
   - System Architecture
   - Class Diagram
   - Class Descriptions, Attributes and Methods
   - Relationships Between Classes
   - Database Design, if applicable
   - User Interface Design

10. Implementation

11. Testing and Test Cases

12. Results

    Results should include:
    - Screenshots of the user interface
    - Sample inputs and outputs
    - Brief description of the application's functionality

13. Conclusion and Future Enhancements

14. References

15. Appendices

Appendices may include:
- User Manual and Installation Instructions
- Selected Source Code
