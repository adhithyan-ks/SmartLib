\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Academic libraries serve as the intellectual cornerstone of collegiate institutions, coordinating the acquisition, cataloging, circulation, and preservation of scholarly assets. Despite widespread digitization across universities, many institutional libraries continue to grapple with antiquated management software or error-prone manual ledgers. Common systemic drawbacks include cumbersome book circulation workflows, unmonitored overdue loans leading to substantial fee leakages, double-booking race conditions during manual reservations, and the complete absence of a secure, transparent self-service portal for enrolled students.

To resolve these challenges, this report presents \textbf{SmartLib}, a robust, desktop-based College Library Management System developed using Java SE 17, Swing/AWT graphical user interfaces, JDBC, and a relational MySQL database. Engineered in accordance with the curricular requirements of course \textbf{PBCST304 (Object Oriented Programming)}, SmartLib strictly adheres to multi-tier layered software architectural patterns, embodying rigorous Separation of Concerns (SoC) and the Dependency Inversion Principle (DIP). The architecture cleanly delineates responsibilities across four distinct layers: a responsive Presentation Layer employing Swing's \texttt{CardLayout} navigation model, a Business Service Layer encapsulating institutional policies, an abstracted Data Access Object (DAO) Layer centered around a generic \texttt{CrudDAO<T, ID>} base interface, and a persistent MySQL relational database.

SmartLib introduces innovative operational features that elevate collegiate library administration. A unified authentication mechanism with 12-round BCrypt cryptographic password hashing provides role-based access control for both Librarians and Students. Librarians benefit from an advanced Circulation Desk equipped with real-time Active Borrowings Management, which provides a live 10-column inventory of active loans, dynamic clock-aware overdue calculations ($\text{Fine} = \text{Days Overdue} \times \text{\rupee} 10$), multi-criteria instant filtering, and single-click return processing. An automated Title Reservation subsystem eliminates concurrency conflicts through a First-In, First-Out (FIFO) queue that proactively triggers fulfillment notifications upon book returns. Concurrently, students are empowered through a dedicated self-service portal featuring catalog exploration, borrowing requests, and real-time fine visibility. 

The software system was verified through an automated test suite comprising 43 unit test cases implemented in JUnit 5, employing mock DAOs and deterministic clock abstractions to guarantee rock-solid business logic integrity. The resulting application delivers an intuitive, secure, and production-grade library automation solution that demonstrates the practical application of object-oriented paradigms to enterprise software development.

\vspace*{1cm}
\noindent \textbf{Keywords:} Object-Oriented Programming, Multi-Tier Architecture, Java Swing, JDBC, Data Access Object Pattern, BCrypt Authentication, Active Borrowings Tracking, JUnit 5 Testing.
